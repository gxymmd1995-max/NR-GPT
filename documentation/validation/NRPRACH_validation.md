# PRACH非受限集合验证

固定TS38.211 V15.2.0 §6.3.3.1/§6.3.3.2及§5.3.2。原表6.3.3.1-1/-2对应13种格式、长度、有效周期/CP；-3/-4对应长/短根映射；-5/-6/-7对应非受限NCS；原表6.3.3.2-1对应RA/UL间隔、RB带宽及k_bar。定向读取原文PDF第20、35、37～41页。未实现原表6.3.3.2-2/-3/-4的完整调度器，MATLAB导出脚本选择合法配置后将所选时机显式映射到Python接口。

## 独立MATLAB实测

实际MATLAB 24.1.0.2537033 (R2024a)、5G Toolbox24.1。[导出脚本](../../examples/prach/export_NRPRACH_reference.m)调用nrPRACHConfig/nrPRACH/nrPRACHGrid/nrPRACHIndices/nrPRACHOFDMModulate，Windowing=0；未用Python生成参考。导出时在0..159的PRACH slot中选择有效时机，保存配置索引、slot、TimeIndex、频段、时间原点等复现输入。混合A2/B2、A3/B3选择最后一个B格式时机。

44个完整波形案例覆盖长0/1/2/3和短A1/A2/A3/B1/B2/B3/B4/C0/C2；FR1短RA15/30及FR2短RA60/120，上行分别30/120kHz，52RB；逻辑根、前导0/63、NCS索引、频域起点、非零时机偏移变化。另32例覆盖长/短各16种非受限NCS，根起点837/137、前导63，覆盖跨根分配、根回绕和NCS=0。没有声称覆盖所有端口/频率组合或参数笛卡尔积。

[实际向量](../../examples/prach/NRPRACH_reference.json)保存复DFT符号和CP+活动时域数据、参数及环境；[比较报告](../../examples/prach/NRPRACH_comparison.json)保存逐例误差、根/移位/NCS一致性、完整64候选检测结果与SHA256。Python接收仅使用实际MATLAB波形、共同资源和0延迟搜索窗口，未把真实前导号传入候选选择。各案例应仅检出实际前导，且delay_samples=0。

DFT模长sqrt(L)，绝对比较容差1e-7；MATLAB对大角度ZC的浮点处理与Python整数相位模2L存在约1e-8量级差异，Python不通过修改真值强行消除差异。归一化波形容差1e-10。当前实测最大DFT误差9.22304435255634e-9、归一化波形误差4.748054948664015e-12；全部76例通过。参数字段必须精确相等。

时间边界单独处理：短格式在跨0/0.5ms边界时扩展CP，FR2 120kHz的ActivePRACHSlot=1对应125微秒物理时间原点，不能因捕获数组从0开始就增加额外CP。C2的2048Ts基CP可包含完整有效周期；Toolbox把该周期放入额外网格符号，Python按协议保留在CP中，整段波形相同。

## 适用边界

实际MATLAB时域验证采用已同步、无信道扰动、单发送端口的独立波形；带噪、复增益、CFO补偿、时延和多UE叠加是Python链路测试。接收为工程循环相关/重复相干平均/天线非相干能量合并，固定门限不是CFAR。D须不超过CP且小于循环移位间隔；估计最强峰而非首径。同一前导碰撞无法区分UE，近远效应和多径泄漏会影响分数及增益估计。

仅非受限集合、显式一次RO、单numerology小区和整数样点；无受限Type A/B、配置表调度、SSB关联、多RO盲扫描、RAR/Msg3、功率爬坡、SIC、盲频偏/分数延迟或多径首径算法。普通NRGrid/NROFDM不用于PRACH，独立频谱图与实际频率位置由PRACH自身给出。本轮未提交或推送。
