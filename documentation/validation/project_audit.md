- 计划将 MATLAB 比对描述为可选，与项目要求不一致；已明确具体物理信道必须进行独立 MATLAB 比对。
- 计划中的当前完成状态、目标目录及实际目录混在一起，已区分已实现的 cell 与未来模块。
- `channel` 与目标目录 `channel_models`、NRGrid 轴顺序的描述不统一，已统一为规划中的目录名和轴约定，不宣称尚未实现的功能已具备。
