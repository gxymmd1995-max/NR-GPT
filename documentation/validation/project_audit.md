# 工程命名与文档一致性检查

日期：2026-10-24。已随双工、天线和精确时序扩展更新结果。范围为当前 NRCell 实现、测试、示例、总体文档及协议资料登记；不修改协议原文或译文。本记录描述本地验证结果，远端提交和 CI 状态以 GitHub 实际记录为准。

## 发现并修正

- 类源码已经改为 `NRCell.py`，示例、测试、MATLAB 函数及图片/JSON 名仍使用旧的 `nr_cell`。已统一为 `NRCell`，保留 `test_`、`plot_`、`export_` 等用途前缀，并同步所有导入、函数入口和文档引用。
- 计划仍提及当前目录不存在的 R18 PDF，已按现有资料清单修正。
- 计划将 MATLAB 比对描述为可选，与项目要求不一致；已明确具体物理信道必须进行独立 MATLAB 比对。
- 计划中的当前完成状态、目标目录及实际目录混在一起，已区分已实现的 cell 与未来模块。
- `channel` 与目标目录 `channel_models`、NRGrid 轴顺序的描述不统一，已统一为规划中的目录名和轴约定，不宣称尚未实现的功能已具备。
- 类说明中 CP 默认值、索引方法的参数/返回值/异常、完整字典输出及替换载波后 BWP 的处理不够详细，已补充。
- 缺少示例目录 README 与 JSON 数据结构说明，已增加，解释 Python 配置和 MATLAB 期望值的不同用途。
- 规范清单缺少实现到原文章节的索引，已补上，并核对实际文件哈希。
- 验证报告将循环读取 18 个 MATLAB 配置称为参数化 pytest 入口，且写成已提交向量；已准确说明测试项数与本地未提交状态。
- 统一各文档的完整测试命令，明确远端 CI 尚未运行，不能将配置存在视为验证通过。

## 检查方法与结果

- 比对 NRCell 的 dataclass 初始化字段、类常量、只读属性及自行实现的方法与同级 Markdown：12 个字段、8 个常量、35 个属性、8 个类方法及模块内部校验函数均有说明。
- 检查项目维护的 全部 Markdown 本地链接、图片链接及大小写，全部有效；排除用户提供的协议译文中的外部原文引用。
- 检查规范清单内 8 份文件的 SHA-256，与目录中的实际文件逐项对应。
- 运行 116 项 pytest 测试，含 78 组 MATLAB 数据、34398 项整数输出检查，全部通过；源码行/分支覆盖率均为 100%。
- 运行源码 doctest 和类说明中的全部 Python 代码块，确认示例可执行。
- 运行 Python 演示与绘图脚本，并用重命名后的 MATLAB 入口重新导出参考数据。
- 对新图进行人工查看，确认标注、轴标签和规范出处可读。

以上结果仅针对当前 NRCell 功能。未来物理信道实现、RF 参数组合和完整 R15 一致性认证不在本次通过结论内。
