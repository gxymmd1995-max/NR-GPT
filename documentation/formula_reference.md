# 公式变量阅读指南

本指南是项目辅助说明，不是3GPP协议原文或标准参数表。规范固定为项目R15基线；每节注明规范版本和原文章节，未印公式号的表达式不新增冒充原文的编号。协议原表范围与高层配置约束仍以同版英文原文为准。

<a id="conventions"></a>
## 类型、单位和维度约定

- **范围分三种**：规范枚举/公式范围、当前代码校验范围、随资源配置计算的范围。表中出现“代码”仅描述当前实现，不扩大为整个协议允许范围。参数无固定上限时给出依赖关系，不凭空给最大值。
- **标量与数组**：写`[Rx,P,D]`表示三个轴长度分别为接收支路、发送逻辑端口、因果tap数；单个下标元素是标量。“每符号标量”不表示函数返回单个数，返回值可由这些标量组成数组。
- **基数与坐标**：项目Python索引从0开始。MATLAB线性地址从1开始。slot局部符号、子帧符号、帧内slot、SFN不可混用；CRB以Point A编号，PRB以BWP编号，资源网格k通常以载波起点编号，FFT有符号bin以DC为0。
- **时间**：`s`为秒；`sample`为当前采样率下一个采样点；协议`N_CP`通常是Tc个数，必须乘Tc才是秒。`Nfft`是FFT采样点数，并非Tc数。`sample/Fs`得到秒，`Tc_count*Tc`也得到秒。
- **频率**：频率与时间乘积进入指数前统一为Hz×s；API中kHz与Hz按1000换算。SCS、RF载频f0、残余CFO是三种不同频率。
- **幅度与功率**：复幅度是归一化数值，功率取平方模。复白噪声方差指E(abs(n)**2)，不是单个实分量方差。beta为线性幅度，功率系数应取beta²；10log10用于功率比，20log10用于幅度比。没有RF阻抗/增益标定时不写成W或dBm。
- **相位**：角度以rad计，序列循环移位alpha是逐序列点相位步长；`exp(j*alpha*n)`的指数无量纲。TA样点正值提前，理想信道delay样点正值延迟，符号不同。

| 记号/操作 | 逐项含义 | 范围、单位、维度 |
|---|---|---|
| $j$ | 虚数单位，将相位写为复指数 | 范围：固定j²=−1；求和下标中的同名j另按局部定义；单位：无量纲；维度：复常量 |
| $\pi$ | 圆周率，弧度相位换算的常数 | 范围：固定约3.141592653589793；单位：无量纲；维度：实常量 |
| $e$ | 自然指数底，构造指数函数 | 范围：固定约2.718281828459045；单位：无量纲；维度：实常量 |
| $\lfloor x\rfloor$ | 向下取整，返回不大于x的最大整数 | 范围：x为有限实数，结果为整数；单位：输入须先使用一致单位；维度：标量运算 |
| $\lceil x\rceil$ | 向上取整，返回不小于x的最小整数 | 范围：x为有限实数，结果为整数；单位：输入须先使用一致单位；维度：标量运算 |
| mod | 非负取模操作，将整数折返到长度M内 | 范围：M>0时结果0..M−1；单位：无量纲操作；维度：标量/逐元素运算 |
| XOR | 按位异或操作，实现二进制模2加法 | 范围：二进制输入0/1，输出0/1；单位：无量纲操作；维度：标量/逐元素运算 |
| $\oplus$ | 异或的数学符号，等价于二进制模2加法 | 范围：二进制输入0/1，输出0/1；单位：无量纲操作；维度：标量/逐元素运算 |
| $\sum$ | 对明确索引集合求和，用于合并序列/能量 | 范围：按公式给定有限或收敛索引范围；不默认平均；单位：与被加项相同；维度：沿指定轴归约 |
| $\prod$ | 对明确索引集合求积，用于组合因子 | 范围：按公式给定索引范围；不默认求和；单位：各乘项单位的乘积；维度：沿指定轴归约 |
| $\operatorname{mean}$ | 指定有限样本的算术平均 | 范围：非空样本集合；按公式指定轴求和再除个数；单位：与被平均量相同；维度：沿指定轴归约 |
| $E$ | 随机变量的统计期望，不是单次样本均值 | 范围：分布满足所用期望存在的条件；单位：与随机变量相同；维度：统计运算，形状由随机量确定 |
| 转置T | 交换矩阵行列，不改变元素的复数值 | 范围：适用于矩阵；单位：保留元素物理单位；维度：[a,b]→[b,a] |
| 共轭转置H | 交换矩阵行列并逐元素共轭 | 范围：适用于实/复矩阵；单位：保留元素物理单位；维度：[a,b]→[b,a] |
| 伪逆+ | Moore–Penrose广义逆，用于LS/ZF | 范围：由矩阵SVD等求得，不是逐元素倒数；单位：对线性映射取相应逆单位；维度：输入[a,b]输出[b,a] |
| 平方模 | 复数乘自身共轭，将复幅度换为功率量 | 范围：实数≥0；单位：原复数单位的平方；维度：逐元素运算 |
| Frobenius范数 | 矩阵所有元素平方模求和后开方，用于矩阵归一化 | 范围：实数≥0；零矩阵不能除以其范数；单位：与原矩阵元素同单位；维度：矩阵→实标量 |
| prime | 撇号修饰，表示局部偏移或派生量 | 范围：按所在公式定义，不自动视为导数；单位：随被修饰变量；维度：随被修饰变量 |
| bar | 上横线修饰，区分基准或中间量 | 范围：按所在公式定义，不自动视为统计均值；单位：随被修饰变量；维度：随被修饰变量 |
| tilde | 波浪线修饰，区分变换前后或预处理量 | 范围：按所在公式定义；单位：随被修饰变量；维度：随被修饰变量 |
| hat | 帽号修饰，表示估计结果 | 范围：按对应估计算法约束，可能带噪声和偏差；单位：与被估计物理量相同；维度：与对应估计对象一致 |
| 空/无定义结果 | `None`表示未检测/不能给建议；`NaN`表示该RB无有效噪声测量 | 都不等于真实功率0；不能无条件转成0参与平均 |

| $x$ | PSS使用的7级二进制m序列 | 0/1，周期127；PSS和SSS初态不同 | bit | 一维周期序列 |
| $x_0$ | SSS使用的第一条7级二进制m序列 | 0/1，周期127；PSS和SSS初态不同 | bit | 一维周期序列 |
| $x_1$ | SSS使用的第二条7级二进制m序列 | 0/1，周期127；PSS和SSS初态不同 | bit | 一维周期序列 |
| $i$ | 7级递推当前位置 | 非负整数；初态i=0..6 | bit索引 | 整数标量 |
| $m_0$ | SSS第一条m序列的循环偏移，编码NID1和NID2信息 | m0=15*floor(N_ID_1/112)+5*N_ID_2，0..40且按式离散 | 序列点偏移 | 整数标量 |
| $m_1$ | SSS第二条m序列的循环偏移，编码NID1剩余信息 | m1=0..111 | 序列点偏移 | 整数标量 |

例如PCI=17，则N_ID_1=5、N_ID_2=2，PSS循环偏移86，SSS的m0=10、m1=5。PSS可区分3个组内标识，SSS与PSS联合确定1008个PCI。



## 读矩阵公式时逐步核对维度

以当前SRS接收机的2用户、每用户2端口、4Rx、8tap、576个观测RE为例：

| 步骤 | 输入形状与所代表的轴 | 运算后的形状 | 为什么匹配 |
|---|---|---|---|
| 建模 | 每UE参考[L,K,2]、延迟基[576,8] | 联合A[576,32] | 一列对应一个UE/端口/tap组合，2*2*8=32 |
| 取观测 | 接收网格[4,L,K]，抽取观测并转置 | Y[576,4] | 每行一个不同RE，每列一个Rx |
| 估计 | A+ [32,576]、Y[576,4] | h_hat[32,4] | 矩阵乘法收缩共同的576观测轴 |
| 还原单UE CIR | 从32行中取该UE的16行，再按端口/tap重排 | CIR[4,2,8] | 16=2端口*8tap，Rx轴保留 |
| 生成频率响应 | CIR[4,2,8]、频率基[K,8] | H[4,2,K] | 对8个tap求和，频率K逐点求值 |
| 选码本 | 已探测频点H[F,4,2]、候选W[2,r] | G[F,4,r] | 收缩发送端口轴2；F只取实际探测频点，不直接使用全部K |

此例的576是具体SRS配置下的观测RE并集数；用户RE重叠时，不能把两用户各自576相加为1152。同一UE内端口复用RE也不会增加不同观测行数。维度满足仅是必要条件，A仍须列满秩且条件数不超过门限。
